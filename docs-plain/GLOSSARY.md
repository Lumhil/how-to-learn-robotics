# 术语速查表

> 读白话版任何一篇时忘了某个词，回来查这里。每条一句话，按主题分组；词后面标注首次详细出现的章节。

## 入门篇（机器人学入门）

| 术语 | 一句话解释 |
|------|-----------|
| **位姿**（Pose） | 位置（在哪）+ 姿态（朝哪），描述一个坐标系的完整状态 |
| **齐次变换矩阵** | 一个 4×4 矩阵，同时装下"旋转 + 平移"，让坐标变换只用一次矩阵乘法 |
| **旋转矩阵** | 3×3 矩阵描述朝向；每一列是新坐标系的轴在旧坐标系里的指向 |
| **欧拉角** | 用三个转角（如偏航/俯仰/滚转）描述姿态；简单但有先天缺陷 |
| **万向节死锁**（Gimbal Lock） | 欧拉角在特定姿态下三个转轴"挤在一起"、丢失一个自由度的现象 |
| **四元数**（Quaternion） | 用 4 个数表示旋转，避开死锁；机器人/游戏引擎的标准姿态表示 |
| **正运动学** | 已知各关节角度 → 算出末端（手）在哪 |
| **逆运动学** | 已知末端要去哪 → 反算各关节角度；可能无解或多解 |
| **DH 参数** | 给每个关节"贴坐标系"的统一规则；相邻关节关系用 4 个数字（两距离两角度）说清 |
| **雅可比矩阵**（Jacobian） | "传动比表"：关节速度 ↔ 末端速度的换算表；也能把末端力换算回关节力矩 |
| **伪逆** | 矩阵不可逆时"凑合用的逆"，数值逆解和零空间计算都靠它 |
| **奇异点** | 某些手臂姿势下机器人在某方向"突然动不了"，雅可比失效；构型固有属性，无法消除 |
| **动力学** | F = ma 的机器人版："要这么动，每个关节该出多大力" |
| **牛顿–欧拉法** | 动力学建模法：逐节算加速度（从底座往外）、逐节传力（从末端往回）；适合编程 |
| **拉格朗日法** | 动力学建模法：从能量角度列方程；纸面优雅，高自由度会爆炸 |
| **转动惯量** | "转起来的物体有多难被改变转速"，旋转版的质量 |
| **PID 控制** | "差多少补多少"的经典控制：比例（看现在）+ 积分（看过去）+ 微分（看未来） |
| **前馈**（Feedforward） | 用模型预先算出控制量大头，不等误差出现就发力；PID 只修零头 |
| **阶跃响应** | 目标值瞬间跳变时系统的反应；硬件有惯性，猛跳会超调、振荡 |
| **T 形 / S 形速度曲线** | 平滑加减速的轨迹形状：T 形速度连续，S 形加速度也连续 |
| **标定**（Calibration） | 用实测数据修正运动学参数（杆长、装配偏差），让"图纸模型"贴近真机 |
| **辨识**（Identification） | 同上，针对动力学参数（质量、转动惯量、摩擦） |
| **最小二乘** | "找一组参数让预测与实测的总平方误差最小"的标准求解套路 |
| **直驱** | 电机不经减速器直接带动关节；摩擦小，是很多实验的前提 |
| **减速比** | 减速器的"转速降多少倍/力放大多少倍"，如 86:1 = 电机转 86 圈关节转 1 圈 |
| **拖动示教** | 协作机器人的功能：人手握着机械臂，它顺从地跟着走 |
| **阻抗控制 / 力控** | 让机器人末端表现得像一根可控的弹簧，用于打磨、装配等接触作业 |
| **示教再现 / 示教器** | 工业机器人最主流用法：人拿遥控器（示教器）逐点教路径，机器人重复执行 |

## 进阶·现代机器人学

| 术语 | 一句话解释 |
|------|-----------|
| **欧式空间** | "平直"的空间，像无限大桌面：能加减、能插值、两点最短路径是直线 |
| **李群** | "光滑的弯曲空间 + 一套自洽运算"；机器人里最重要的两个是 SO(3) 和 SE(3) |
| **SO(3)** | 所有三维旋转组成的姿态空间 |
| **SE(3)** | 三维旋转 + 平移，即所有"位姿"组成的空间 |
| **李代数** | 弯曲空间上某点的"切平面"，小范围内可以当平直空间用；角速度住在这里 |
| **Exp / Log（指数/对数映射）** | 在"弯曲空间"和"切平面"之间来回搬运的一对操作 |
| **测地线**（Geodesic） | 弯曲空间里的"直线"（最短路径），如地球上的大圆航线 |
| **旋量**（Screw） | 把"绕哪根轴转 + 沿轴走多远"打包成一次螺旋运动 |
| **指数积**（PoE） | 把各关节的螺旋运动逐个"乘"起来的建模法，《Modern Robotics》的骨架 |
| **Slerp** | 四元数球面插值；本质是姿态空间里沿测地线的"直线插值" |
| **Bezier 曲线** | 多层线性插值嵌套出的平滑曲线；李群语言下可推广到任意空间 |
| **流形** | 局部看起来像平面、整体弯曲的空间（地球表面就是二维流形） |
| **零空间 / 约束流形** | 零空间：完成任务之外"多余"的自由度方向；约束流形：满足约束的状态连成的弯曲的"面" |

## 进阶·3D 视觉

| 术语 | 一句话解释 |
|------|-----------|
| **计算机视觉 vs 机器视觉** | 前者研究"看懂图像"本身；后者为机器人服务："看见 → 定位 → 动手" |
| **针孔模型** | 相机成像的几何抽象：空间点、光心、像点三点一线 |
| **内参** | 相机自身参数（焦距、主点、畸变），出厂决定，与装在哪无关 |
| **外参** | 相机坐标系相对世界坐标系的位姿（装在哪、朝哪） |
| **张正友标定法** | 拍标定板照片反推内参的经典方法，OpenCV 的默认实现 |
| **手眼标定 / AX=XB** | 求相机与机器人之间安装关系的方程；A、B 是两次运动的已知量，X 是要求的安装关系 |
| **眼在手外 / 眼在手上** | 相机固定在旁边（eye-to-hand）vs 装在机械臂末端（eye-in-hand） |
| **PnP** | 已知物体上若干 3D 点和它们在照片上的 2D 位置，反推物体（相机）位姿 |
| **特征点**（SIFT） | 图像里"换个角度、光照也能认出来"的局部纹理记号 |
| **点云** | 一大堆带三维坐标的点，深度相机的直接输出 |
| **ICP** | 迭代最近点：让两片点云一点点对齐的配准算法 |
| **开环 vs 闭环** | 开环：看一眼算一次闭眼动（误差全累积）；闭环：持续看着持续修正（误差不累积） |
| **视觉伺服** | 用视觉实时误差直接驱动控制器的闭环方案 |
| **SLAM** | 同时定位与建图："我在哪、周围地图长什么样"，移动机器人的感知主线 |

## 进阶·自主规划

| 术语 | 一句话解释 |
|------|-----------|
| **构形空间**（C-Space） | 所有关节角度组合成的空间；机器人在其中坍缩成一个"点" |
| **维度诅咒** | 网格数随自由度数指数爆炸（6 关节 × 60 档 ≈ 470 亿格），规划领域一切困难的源头 |
| **路径 vs 轨迹 vs 运动规划** | 路径=纯几何路线（不带时间）；轨迹=路径+时间表；运动规划=总称 |
| **完备性** | "只要有解，有限时间内一定找到"的算法保证 |
| **最优性** | "找到的解在给定指标下最好"的算法保证 |
| **A\* / Dijkstra** | 图上找最短路的经典搜索算法（地图导航同款）；A\* 加了启发式、更快 |
| **人工势场法** | 目标吸引、障碍排斥，用"虚拟力"拽着机器人走；快，但会卡在局部极小 |
| **局部极小值** | 优化版"四面都是上坡的坑"：不是终点，但算法出不来 |
| **PRM** | 先随机撒点建"路网"、再反复查询的采样规划法 |
| **RRT** | 从起点快速生长随机树探索空间的规划法；高维机械臂主流，概率完备、不最优 |
| **RRT-Connect / RRT\*** | RRT 改进版：前者双向生长（快），后者渐进最优 |
| **概率完备** | 弱一点的完备性："撒点足够多就几乎一定能找到解" |
| **时间最优轨迹规划**（TOPP） | 在电机力矩（而非人为速度限制）约束下，沿给定路径算出最快走法 |
| **梯度投影法** | 把"避障、离关节极限远点"等目标的梯度投进零空间，边做任务边自保 |
| **运动策略**（Motion Policy） | 不算完整轨迹，根据当前状态实时输出下一个动作 |
| **MPC**（模型预测控制） | 每个控制周期在线解一小段轨迹优化、只执行第一步、下周期滚动重来 |
| **MDP** | 马尔可夫决策过程："状态 + 动作 → 回报"的数学框架，规划和强化学习的共同语言 |
| **VLA** | Vision-Language-Action 模型：输入图像和指令、直接输出动作的大模型 |

## 具身智能

| 术语 | 一句话解释 |
|------|-----------|
| **机器学习 / 深度学习** | 不写死规则，给通用模型喂数据让它自己拟合规律；用多层神经网络的叫深度学习 |
| **强化学习**（RL） | 试错 + 奖励：做得好给分，逐渐学出"什么状态该做什么"（策略） |
| **贝尔曼方程** | 强化学习的全部理论源头：当前价值 = 立即回报 + 之后的回报（打折） |
| **MDP / 策略 / 价值** | 见"自主规划"组；策略=状态到动作的映射，价值=一个局面有多好 |
| **动态规划 / 蒙特卡洛 / TD** | 求解 MDP 的三大经典方法（DP≈Dijkstra、MC≈随机模拟、TD=边走边学） |
| **函数逼近 / 深度强化学习** | 状态太多存不下"查找表"，改用函数（神经网络）代替表——后者即 DRL |
| **模仿学习 / 示教学习**（LfD） | 从人类示范的数据里学动作，而不是靠试错 |
| **具身智能**（Embodied AI） | 让 AI 拥有身体，通过感知和行动来学习的智能 |
| **ROS** | Robot Operating System，机器人开源生态的事实标准；直接学 ROS 2 |
| **bin picking** | 乱箱抓取：从散乱堆叠的零件箱里把物体一个个抓出来 |
