# 先修知识（白话版）

> 原文：[docs/prerequisite.md](../docs/prerequisite.md)

## 最重要的一句话

**不要等"准备好了"再开始学机器人。** 机器人学涉及面太广，不同方向需要的基础完全不同，如果一开始就埋头补数学，大概率陷在"先修知识"的泥潭里出不来。

原文有个很妙的比喻：数学像火影里的**写轮眼**——同样一块石碑，只会加减乘除的人看到的是普通石碑，学了线性代数、微积分的人能看到第二层，学了计算方法、凸优化、微分几何的人能看到第三层。**先够用，随着研究深入再升级眼睛。**

按"什么时候需要"把清单分成两档：

## 第一档：最好现在就有

| 项目 | 为什么需要 | 推荐资源 |
|------|-----------|---------|
| **基本英文阅读** | 写得深入浅出的经典教材几乎都是英文的。硬着头皮读一个月就习惯了 | —— |
| **线性代数** | 机器人的一切计算（位置、朝向、运动）都是矩阵运算 | Gilbert Strang《Linear Algebra》：[YouTube](https://www.youtube.com/watch?v=hNDFwVVKVk0&list=PL221E2BBF13BECF6C) / [网易公开课（中字）](http://open.163.com/special/opencourse/daishu.html) |
| **微积分** | 只要涉及"变化率"（速度、加速度）和"累积"，就要用导数和积分 | Strang《微积分重点》：[网易公开课](http://open.163.com/special/opencourse/weijifen.html) |
| **Matlab 或 Python** | 用来快速验证你推导的公式对不对，画图看结果。会基本的矩阵操作和画图即可 | Coursera 入门课：[Matlab](https://www.coursera.org/learn/matlab) / [Python](https://www.coursera.org/specializations/python) |

线性代数特别多说一句：Strang 这门课从"空间"的角度讲线性代数（向量是一段空间中的方向、矩阵是一次空间变换），而不是教你算行列式——这正是机器人学需要的思维方式。

## 第二档：可以边学边补

| 项目 | 为什么需要 | 推荐资源 |
|------|-----------|---------|
| **理论力学** | 机器人天天和力、运动打交道。很多初学者就是死在教材的动力学章节的 | 学堂在线清华高云峰《理论力学》公开课 |
| **控制理论** | 让机器人"听话"的学问。至少了解 PID、状态方程、稳定性这些词 | Brian Douglas 的视频（YouTube 原版 / [B 站中字版](https://www.bilibili.com/video/BV1WT4y1M7rm)） |
| **数字电路与模拟电路** | 知道电机为什么需要驱动器，能自己搭小电路做控制实验 | 随便一本教材即可 |
| **一点单片机** | 让控制代码真正跑在电路里。买个带伺服电机教程的最小系统板，学 Arduino 或 STM32 | 最好参加一次 RoboMaster 或智能车竞赛 |
| **Linux 和 C 语言** | 机器人软件几乎都跑在 Linux 上 | [《C语言入门》](https://akaedu.github.io/book/pt01.html)，边学边装个 Ubuntu |
| **基本 3D 设计** | 做实验平台时自己设计小零件，配合 3D 打印快速出原型 | SolidWorks |

## 两个现代武器

- **B 站**：大量国外课程、Coursera 课程都有免费带字幕搬运，还有很多前辈自制的教程，搜就是了；
- **AI 工具**：如今大语言模型的专业水平已远超绝大多数人——让它解释看不懂的概念、帮你写验证代码、查资料、跟你讨论，都事半功倍。**有机会一定要用上最好的模型。**

---

以上全部加起来，大致相当于一个自动化或机电专业大三学生的水平。有了第一档，就可以直接开始看机器人学了；缺第二档，遇到了再回来补。
