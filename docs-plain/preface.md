# 前言（白话版）

> 原文：[docs/preface.md](../docs/preface.md)

这一章回答一个问题：**这本书为什么存在？**

## 一个反常的现象

作者面试过很多从事机器人研究的求职者。从履历上看，他们毕业于机电、计算机等专业，甚至来自机器人实验室、机器人公司，都是"专业选手"。但一聊就发现：绝大多数人**缺少机器人学的完整知识体系**——

- 画电路板的，不知道怎么做机器人的工作空间分析；
- 设计机构的，不知道动力学怎么用在控制上；
- 写控制算法的，没听过"构形空间"；
- 做运动规划的，不知道什么是 Q-learning（一种强化学习方法）；
- 做深度强化学习的，不知道学出来的控制指令怎么让真机器人动起来。

每人都会一小块，但拼不成整图。

## 作者自己的经历

他博士入学时接手了师兄的一台 SmartPal 机器人，靠"祖传代码"做过演示。后来认真读代码才发现：程序实际发给机器人的，只是**几个关节位置点**而已。

**"PID 在哪里？？？"**——PID 是控制里最经典的算法（入门章会讲），他预期的"控制"根本不在代码里。这个问题他在实验室问了一圈没人答得上，选修了好几门研究生课程、学了一年，还是没答案。连国内最早开展机器人研究的院校之一，研究生课程也只教了建立 DH 坐标系（一种建模方法）、简单算了个平面三连杆，控制、轨迹规划、运动学逆解统统没涉及。

## 结论

国内机器人学**还没有形成完整的教学体系**，学生只靠上课接触不到这些非常基础的知识，只能做项目时缺什么补什么——所以造就了一大批"没算过运动学逆解的机器人专业硕博生"。这不是学生的问题，也不是这些知识有多难，而是**没人给你一张完整的地图**。

国外和港台高校的教学体系相对完整，大作业基本覆盖主要知识点、要求编程实现。但好消息是：国内学生很聪明，只要有一些正确的引导，很快就能自学补齐。

这本书，就是那张地图。
