# 进阶导言（白话版）

> 原文：[docs/advanced.md](../docs/advanced.md)

走到这里，你已经是个不错的机器人工程师了——能让机械臂按你的要求精确地动。但**研发**工作需要更多专业知识。

先分清两个部分的边界，一句话：

- **入门**讲的是"示教再现"式的传统机械臂——怎么让机器人**动起来、动得好**；
- **进阶**要解决的是让机器人拥有一定的**自主决策能力**、应对环境的变化——业内叫"**基于感知的规划与控制**"（简称"规控"）。

进阶部分按三条主线组织，每条一章，彼此独立、可按需切入：

| 主线 | 章节 | 回答的问题 |
|------|------|-----------|
| **数学语言** | [现代机器人学](modern-robotics.md) | 入门部分埋下的疑惑（欧拉角、角速度、四元数）一次清算，还给你两件趁手的兵器 |
| **感知** | [3D 视觉](3d-vision.md) | 打通"看见 → 定位 → 动手"的链路 |
| **决策** | [自主规划](motion-planning.md) | 从"人教机器人"走向"机器人自己算" |

最后的[进阶实践](advanced-practice.md)给这三章配公开课和动手清单。

另一个实用建议：**入手一本《Springer Handbook of Robotics》**（机器人学手册，2000 多页的大部头）。它不是拿来读的，是拿来查的——每次接触一个新领域，先翻到对应章节看大纲、顺藤摸瓜找参考文献，这是快速进入陌生领域的标准姿势。
