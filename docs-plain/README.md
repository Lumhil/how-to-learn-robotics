# 白话版导读

这是 [`docs/`](../docs/) 中文原书的**白话重写版**：面向第一次接触机器人学 / 具身智能的读者，不假设你有任何机器人背景。原书的定位是"自学路线图"，知识点密度很高；这一版的目标只有一个——**让你看得懂**。

## 两版怎么配合用

- **先读白话版**：建立"这一章在讲什么、为什么需要它"的直觉；
- **再翻原文**：原文里有更完整的资料链接、图片和作者经验，白话版里所有推荐资源也都保留了。

每篇白话版开头都附了对应原文的链接，术语与原文保持一致，方便对照。

## 全书在讲什么（一分钟版）

一台机器人从"一堆零件"到"能干活"，要闯过四关，这本书就是按这个顺序展开的：

1. **让它动起来**（入门）：数学建模 → 求解 → 控制，对应工厂里最常见的机械臂；
2. **让它看得见**（3D 视觉）：装上相机，知道东西在哪；
3. **让它自己想**（自主规划）：不用人一步步教，机器人自己算出怎么绕开障碍把活干了；
4. **让它自己学**（具身智能）：不写死规则，让机器人从数据和试错里自己学。

## 本版的写法约定

- **公式只留骨架**：全书只保留 4 个初中水平的公式（F=ma、线性插值、末端速度=雅可比×关节速度、AX=XB），每个都跟着一句"说白了"告诉你它在干什么，不带你推导；
- **术语第一次出现就解释**：黑体字是术语，括号里是白话解释——想用英文原词搜资料（英文搜索结果质量更高）或忘了词义，查[术语速查表](GLOSSARY.md)；
- **图片沿用原书**：路径指向原书 `docs/images/`，在本地或 GitHub 上都能正常显示。
