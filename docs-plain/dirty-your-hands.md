# 入门实践（白话版）

> 原文：[docs/dirty-your-hands.md](../docs/dirty-your-hands.md)

看完 Craig 的书只是"纸上谈兵"。这一章讲三件事：**用代码验证理论、上手真东西、进入开源世界**。口号只有一句：**Get your hands dirty!**（把手弄脏——动手去。）

## 一、编程练习：一个周末就能做完

纯代码，一台电脑就行。工具用 Peter Corke 的 [Robotics Toolbox for Python](https://github.com/petercorke/robotics-toolbox-python)（`pip install roboticstoolbox-python`；MATLAB 党用 [MATLAB 版](https://petercorke.com/toolboxes/robotics-toolbox/)）。

**关键原则：工具箱是拿来"对答案"的，核心公式必须自己写。** 就像做数学题不能直接抄答案，但答案能告诉你对不对。

三个必做（对应入门章的三块内容）：

1. **列 DH、写正解**（运动学）：挑一台常见六轴（工具箱内置的 PUMA560、UR5 都行），自己列 DH 参数、自己写正运动学，用工具箱的 `fkine` 对答案；
2. **算雅可比**：按教材的几何法写一遍，再用数值差分写一遍，两者对照；顺手用代码验证"为什么不能直接对欧拉角求导"；
3. **数值逆解**：自己写一个雅可比迭代求解器，用工具箱的 `ikine` 对答案。

两个选做（量力而行）：三轴机械臂的牛顿–欧拉动力学递推（对照工具箱的 `rne`）；六轴解析逆解的完整推导。

有条件摸硬件的（实验室、公司）：入门章说的**单轴伺服平台** + **辨识/碰撞检测/拖动示教**复现一遍，是最快的进步方式。

## 二、动手：比赛要参加，但两次就够

机器人是实践学科，只停留在理论"不仅无用、而且无趣"。本科生强烈建议参加 RoboMaster、智能车竞赛、电设等比赛，或加入学校的科技组织——主要是熟悉电路、培养手感、体验"用代码让机器动起来"的快感。

但作者有个冷静的观察：**很多比赛大牛理论学习反而弱**。因为比赛拼的是系统 tricks 而非理论深度，而且"每天很忙"容易制造虚假的充实感（忙着重复低级工作），让人困在局部最优出不来。

所以他的建议是：**完整参加两次比赛就够了**，之后迅速把重心转回理论。

另外，有机会一定要体验一次**示教再现**：拿示教器带着真机走几个点（或用 ABB 的 RobotStudio 仿真软件，做得相当还原）——体会一下全世界工业机器人应用工程师的日常，以及它**有多难用**。这个糟糕的体验，是理解后面"自主规划"为什么重要的钥匙。

## 三、ROS：进入开源世界

到这一步你会发现：机器人是个巨大的系统，初学者不可能每个模块都自己从零写。该拥抱开源了——**ROS**（Robot Operating System，机器人操作系统）是机器人领域的事实标准开源生态。注意：ROS 1 已于 2025 年停止维护，**直接学 ROS 2**。

但很多机电、自动化背景的人直接看 ROS 教程会撞墙——缺 Linux 和 C++ 的底子。作者给的学习顺序：

1. **Linux**：装个 Ubuntu，过一遍 [UNIX Tutorial for Beginners](http://www.ee.surrey.ac.uk/Teaching/Unix/)；
2. **GitHub**：ROS 项目几乎都托管在 GitHub 上，学会用 git 管理代码。还可以从给开源项目提小修改开始练手（作者的第一个 PR 就只是[删了个多余的分号](https://github.com/stack-of-tasks/pinocchio/pull/672)）；
3. **C++ 基础**：ROS 的主体是 C++ 写的。推荐学堂在线清华郑莉老师的《C++ 语言程序设计》基础+进阶，在 Ubuntu + VSCode 环境里学；
4. **数据结构**（可选，为了走得更远）：清华邓俊辉《数据结构》上下；
5. 然后，**直接看 ROS 2 官方教程**（[docs.ros.org](https://docs.ros.org/)）——开源项目最好的教程永远是官方文档。学会它的通讯机制和 colcon、ros2 launch、Rviz 这些基本工具，再按研究方向深入。

有条件配一台 ROS 支持好的硬件平台（TurtleBot、Franka Panda、UR 之类）学习效率会高很多。

**关于 ROS 能不能做实时控制**（很多人纠结的问题，白话版结论）：

- 需要几 kHz 以上刷新率的**电流环、力矩环**：不管哪代 ROS 都不合适，它们跑在驱动器、EtherCAT 从站（EtherCAT 是工业上常用的高实时性通讯总线）或单片机上；
- 100 Hz–1 kHz 的**阻抗控制、全身控制、MPC**：ROS 2（ros2_control / micro-ROS）配上实时内核和配置是可以胜任的——但不是开箱即用，得自己把实时相关的组件配齐。

有了 ROS，SLAM、导航、运动规划这些"非硬实时"的研究你基本都能做了。
