## 什么是"具身智能"

前面学的都是"**人把规则写给机器人**"：模型怎么建、公式怎么推、算法怎么设计。还有一大类工作反着来——**"机器人从数据里自己学"**：给一个通用模型，喂数据让它自己拟合出规律。这就是机器学习，而"具身智能"（Embodied AI）可以粗暴地理解为：**让 AI 拥有身体——通过眼、手、身体的感知和行动来学习的智能**。

原文计划中的章节：导言（趋势与现状）、机器学习速成、强化学习与全身控制、模仿学习、VLA（视觉-语言-动作模型）/ 世界模型等通用操作探索、冷静的展望、上手。目前只写了"机器学习"和"强化学习"两节，以下是其白话版。

## 机器学习：为机器人所用，不是转行

作者的学习路径（三步）：

1. Coursera 吴恩达[《机器学习》](https://www.coursera.org/learn/machine-learning)——了解基本概念；
2. Geoffrey Hinton 的[《Neural Networks for Machine Learning》](https://www.youtube.com/playlist?list=PLoRl3Ht4JOcdU872GhiYWf6jwrk_SNhz9)（YouTube）——过一遍经典神经网络；
3. 上手[PyTorch](https://pytorch.org/) 这类开源深度学习平台，做机器学习的人极多，网上自学资料俯拾即是。

**学它的目的是当工具，不是转行做深度学习**。机器人研究里机器学习的典型用法：

- **智能控制**：用网络学出控制律；
- **建模**：不好建模的环节（比如入门章说"至今没有通用模型"的**摩擦力**），不妨用神经网络拟合；
- **视觉**：深度学习在视觉领域发展迅猛，借来快速搭原型；
- **强化学习**：见下。

近年随着"具身智能"概念兴起，出现了一些相当惊艳的效果（穿鞋带、叠衣服这类传统规控方法很难做到的事）——虽然作者判断目前整体还处于"过拟合"状态（在特定任务上练出来的，泛化能力存疑），但它确实给机器人领域带来了新东西。

## 强化学习：试错 + 奖励

**强化学习**（Reinforcement Learning, RL）的思想极简、极符合直觉：智能体在环境里不断**尝试**，做得好给**奖励**、做得差给惩罚，久而久之学出"什么状态下该做什么"（策略）。

它的全部理论几乎都源自一条**贝尔曼方程**（Bellman Equation）：

$$\text{当前状态的价值} = \text{立即回报} + \text{之后所有回报（打折后）}$$

**说白了：一个局面好不好，取决于眼前能得到多少、加上之后的日子过得怎么样。** 就这一句话，推出了整个领域。

入门必读 Sutton & Barto 的[*Introduction to Reinforcement Learning**](http://incompleteideas.net/book/the-book-2nd.html)（被奉为"圣经"），GitHub 上有[配套 Python 实现](https://github.com/ShangtongZhang/reinforcement-learning-an-introduction)。读书的路线，也是这门学科自己的进化史：

1. 从贝尔曼方程推出**动态规划**（DP）、**蒙特卡洛**（MC）、**时序差分**（TD）等方法；
2. 你会发现 RL 的本质是学一张**查找表**：什么状态 → 什么动作/价值；
3. 状态太多存不下表？→ **函数逼近**（Function Approximation）：用一个函数代替表；这个函数如果是神经网络，就是现在火热的**深度强化学习**（DRL）。

但比这些方法更重要的是理解**马尔可夫决策过程**（MDP，"当前状态 + 动作 → 下一状态 + 回报"的数学框架，自主规划章末尾已经打过照面）——它不仅能描述运动规划（DP ≈ Dijkstra、MC ≈ RRT），还能描述更高层的任务规划。

近年强化学习给机器人控制（尤其**足式机器人**）带来了飞速进步——例如宇树的机器人动作，至少从效果上已不逊于波士顿动力。作者的判断：**强化学习技术是机器人的未来。**
