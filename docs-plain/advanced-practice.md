# 进阶实践（白话版）

> 原文：[docs/advanced-practice.md](../docs/advanced-practice.md)

老规矩：**Get your hands dirty!** 进阶三章给的是路线，这一章给两样东西：一套成体系的公开课（补理论），一份动手清单（练手感）。

## 一、系统公开课：Coursera 宾大 Robotics 专项

抽出几个月，刷完宾夕法尼亚大学的 [Robotics 专项课程](https://www.coursera.org/specializations/robotics)。它和工业机械臂关系不大，但机器人各领域相通，而且几门课正好对上进阶的三条主线：

| 课程 | 讲什么 | 对应主线 |
|------|--------|---------|
| **Perception** | 相机模型、多视几何。质量非常高，做完大作业能做出 AR（增强现实）那种"虚拟物体钉在真实桌面上"的效果 | 3D 视觉 |
| **Estimation and Learning** | 从高斯分布讲到卡尔曼滤波、粒子滤波——机器人"从不精确的传感器数据里估计真实状态"的工具。大作业从零写 2D 激光建图 | 感知（状态估计） |
| **Aerial Robotics** | 四旋翼无人机的控制。轨迹规划、姿态描述、控制都对机械臂学习极有帮助，作业质量高（带 Matlab 数值仿真，能直观看到自己代码的控制效果） | 数学语言 + 控制 |
| **Computational Motion Planning** | 水平不如前几门，但能快速建立"机器人里有 Motion Planning 这个方向"的认知；大作业手写 A\*、PRM、势场法，顺便了解碰撞检测原理 | 自主规划 |
| **Mobility** | 足式（腿式）机器人控制。看懂波士顿动力的视频不再懵；更重要的是体会"**一个简化的模型也能对控制起大帮助**"——为具身智能篇的强化学习运动控制打底 | 具身智能铺垫 |

再补两份资料：机械臂的视觉控制看 Peter Corke 的 [Robotics, Vision and Control (RVC3)](https://petercorke.com/rvc3-landing/)（Python/Matlab 版都有，覆盖 Perception 部分内容）；无人机方向看北航全权老师的[无人机系列课程](https://rflysim.com/doc/zh/)（带仿真器）。

## 二、动手清单：五项，前两项一台电脑就能开工

配套可运行代码会随开源库放出，但不必等——每一项现在就能用现成开源工具（NumPy/SciPy、OpenCV、PCL、MoveIt）独立完成：

1. **姿态插值实验**（现代机器人学·应用一）：实现 Slerp 与李群 Bezier 过渡，让刚体依次经过三个姿态，画出角速度方向随时间的变化曲线——**亲眼看到**"直线插值在过渡点突变、Bezier 过渡连续"；
2. **平均旋转实验**（现代机器人学的框注）：随机生成一组旋转，分别用欧拉角平均、四元数平均、切空间平均、数值优化四种方法求平均，对比差异——顺手把矩阵指数/对数写熟；
3. **相机标定 + 手眼标定**（3D 视觉）：用 OpenCV 走通全流程——20 张标定板照片求内参，再 `calibrateHandEye` 解 AX=XB。没有真机，仿真里一样能走通；
4. **点云滤波**（3D 视觉的"坑"）：拿任意**深度相机**（能直接测出每个像素距离的相机，如 Kinect、RealSense）或公开数据集的点云，用 PCL 跑一遍体素降采样 + 半径滤波（把点云变稀疏、清掉游离在外的噪点），看离群点被清掉的过程；
5. **MoveIt 规划**（自主规划）：URDF（机器人结构的标准描述文件）→ Setup Assistant（向导式配置工具）→ 仿真跑通运动规划。然后做两个小实验：同一问题连续规划十次，**感受随机采样规划器的"每次都不一样"**；再把一个虚拟视锥加进场景当障碍，复现"不遮挡相机"的约束规划。
