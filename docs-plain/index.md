# 关于本书（白话版）

> 原文：[docs/index.md](../docs/index.md)

这是一本**机器人学自学手册**，作者 qqfly 是一名机器人方向的博士（他做过机械臂动力学辨识、碰撞检测、运动规划等研究）。书里没有讲义式的知识铺陈，而是一条**学习路线**：每个阶段该学什么、看哪本书、上哪门课、动手做什么。

## 这本书为谁写

为**"非科班出身"**的人写——本科不是系统学过机器人学的人。按作者面试的经验，国内绝大多数机电、自动化、计算机专业的毕业生（哪怕读到博士）都属于这一类：会做项目里的某一小块，但没有完整的知识体系。如果你是第一次接触机器人或具身智能，这本书的路径正好从零开始。

## 全书结构

书分四大部分，难度递进，每部分都配了实践：

1. **先修知识**：出发前需要的数学、编程、电子基础；
2. **入门**：怎么让一条工业机械臂动起来——这是全书的 地基，核心是 Craig 的《机器人学导论》；
3. **进阶**：三条主线——更高深的数学语言（现代机器人学）、视觉感知（3D 视觉）、自主决策（自主规划）；
4. **具身智能**（整理中）：用机器学习、强化学习让机器人自己学本领——也就是当前最火的"具身智能"方向。

结尾的"勇者斗恶龙"是一篇短文，回答"学了这些到底有什么用"。
