# 现代机器人学（白话版）

> 原文：[docs/modern-robotics.md](../docs/modern-robotics.md)

入门部分留了几个"想不通也先背下来"的坑：

- 为什么不能直接对欧拉角求导得到角速度？
- 为什么欧拉角会有万向节死锁，逼我们接受四元数？
- 两个姿态之间，"平滑过渡"到底怎么定义？

这一章就是来填坑的。填坑的工具是一套更高级的数学语言——**李群李代数**。名字唬人，但核心思想可以用一句话讲清楚。

## 一、问题的根源：位置住在"平的世界"，姿态住在"弯的世界"

先看**位置**。空间中两个位置 $p_1$、$p_2$，从一处走到另一处的最短路径是**直线**。所以位置可以放心地做加减、插值：

$$p = (1-\lambda)\,p_1 + \lambda\,p_2 \quad (\lambda 从 0 到 1)$$

这就是你熟知的线性插值——两点之间"拉着一条直线滑过去"。

再看**姿态**（朝向）。它就没有这么好命了：不管你用旋转矩阵、欧拉角还是四元数表示，都**不能**用简单的向量加减法在两个姿态之间找到"最短路径"。一个直观的证据：两个旋转矩阵相加，结果连旋转矩阵都不是了。

最好的比喻是**地球表面**。北京飞洛杉矶，在平面地图上画一条直线，但那不是真实最短航线——真实最短的是一条向北弯过去的大圆弧。因为**地球表面是弯曲的，上面根本不存在直线**。

- 位置的空间（三维欧式空间）：像一张无限大的平桌面——**平直**；
- 姿态的空间（记号 SO(3)，所有三维旋转的集合）：像一个球面——**弯曲**。

弯曲空间里的"最短路径"有个专门的名字：**测地线**（Geodesic）。它扮演的角色就是平直空间里的"直线"。

还有一层麻烦：进阶的工作到处要用**优化**（找"最好的那个解"），优化要用**梯度**（下坡方向）。在弯曲空间里，连"下坡方向怎么定义"都成了问题。

数学家早就为这类问题准备好了完整工具箱——**李群李代数**（Lie Group / Lie Algebra）。不用怕名字，往下看，它其实是:

- **李群** = 一个"光滑的弯曲空间"，配上自洽的运算规则。机器人里最重要的两个：SO(3)（所有旋转）和 SE(3)（旋转 + 平移，即"位姿"）；
- **李代数** = 弯曲空间上某一点的"**切平面**"。球面是弯的，但贴着球面上一点放一块小平面，小范围内看东西是平的——普通的向量加减在这里又可以用了。**角速度就住在这个切平面里**（这就是为什么它不能从欧拉角直接求导——欧拉角不是切平面里的坐标）。

在弯曲空间和切平面之间来回"搬运"，用的是一对操作：**Exp（指数映射）和 Log（对数映射）**。入门的"DH 变换矩阵连乘"换成这套语言，就成了**旋量**（Screw，把"绕哪根轴转 + 沿这根轴走多远"打包成一次螺旋运动）和**指数积**（Product of Exponentials, PoE，把各关节的螺旋运动逐个"乘"起来）——这就是《Modern Robotics》整本书的骨架。

!!! info "配套要补的数学"

    - **数值计算方法**（数值微分/积分等）：算法最终要在计算机上跑。教材《Numerical Methods for Engineers》；
    - **凸优化**：很多问题没有解析解（写不出闭式答案），只能列成优化问题用代码求解。Stanford 公开课[《Convex Optimization》](https://web.stanford.edu/class/ee364a/)；
    - **李群李代数**：即本章内容，处理"弯曲空间上的梯度"的标准工具。

## 二、从哪入门：《Modern Robotics》

李群李代数的数学教材对工科生太不友好（名字听着就怪）。推荐从 Kevin Lynch 和 Frank Park 的《**Modern Robotics**》开始——一本面向本科生的教材，写得非常清晰：

- 教材主页：[hades.mech.northwestern.edu](http://hades.mech.northwestern.edu/index.php/Modern_Robotics)（官网免费下载）；
- 配套 Coursera 课程：[Modern Robotics 专项课](https://www.coursera.org/specializations/modernrobotics)。

学完你会掌握**旋量 / 指数积**这套全新建模方式，会发现运动学、动力学建模突然变得简单干净——而且你已经在不知不觉中用上了李群李代数。之后再去啃工科向的李群教材（如 Penn 的 [*Notes on Differential Geometry and Lie Groups*](http://www.cis.upenn.edu/~jean/gbooks/manif.html)），把它和自己方向的问题结合。

两个常见问题（原文作者的回答）：

- **旋量和 DH 哪个好？** 都重要，无优劣。DH 直观、够用；旋量更接近刚体运动的物理本质。类比"牛顿力学 vs 相对论"——合适的场合用合适的工具。**先把传统 DH 学扎实，再学旋量**，两者不冲突；
- **"DH 建模有奇异性而 PoE 没有"是真的吗？** 只对了一半。那是 DH 的**参数化奇异**：相邻两个关节轴接近平行时，DH 里 x 轴的方向定义变得不明确，微小的加工误差会让 DH 参数剧烈跳变（标定文献里专门为此加了个辅助参数）。PoE 避免的是这种"表达方式"的奇异；而机器人本身的**运动学奇异**（入门章说的那种构型奇异）是物理属性，换什么建模都消不掉。

## 三、群的语言：给所有空间统一"加减法"

有人学到这会说："旋量、指数积不就是换了个表示方法吗，也没见多大优势。"——这个认识**不对且危险**。就像刚学线性代数时说"矩阵乘法不就是方程组换个写法"——一开始就拒绝新思维方式，后面线性组合、零空间这些真正的武器出现时就跟不上了。

这一节把视角抬高一层：**"群"到底统一了什么。**

一个物体的所有可能状态凑成一个集合，再给这个集合定义一套**封闭的**基础运算（运算结果还在集合里），就得到一个**群**（Group）。把运算抽象成三个符号：

- **群加法** $\oplus$（状态叠状态还是状态）；
- **零元素** $E$ 和**逆运算** $\ominus$（加法的"减法"）；
- **标量积** $\odot$（把"连续做 $\alpha$ 次加法"推广到实数）。

看两个例子，体会"同一套符号、不同的空间"——第二个例子才是重点：

| 空间 | 状态长什么样 | 这里的"加法"是 | 这里的"减法"是 |
|------|-------------|----------------|----------------|
| 机械臂关节空间 | 各关节角度，如（30°, −10°, …） | 普通向量相加 | 普通取负 |
| 姿态空间 SO(3) | 旋转矩阵 | **矩阵乘法**（旋转叠旋转还是旋转，所以封闭） | 矩阵求逆（转回去） |

姿态空间的"加法"根本不是加法，是**矩阵乘法**；"同一个旋转连做 $\alpha$ 次"也不是乘 $\alpha$，而是要算"矩阵的 $\alpha$ 次幂"——这自然引出了矩阵指数 / 对数，"指数积"里那个"指数"正是这么来的。

### 统一了有什么用？先看一个最普通的操作：插值

"从状态 A 平滑过渡到状态 B"，用这套语言可以写成**同一个套路**：**从起点出发，按比例走完"两者的差"**。公式不用记，看它分别在两个空间落地成什么：

- 在关节空间，"差"就是向量减法、"按比例"就是数乘——落地成你最熟悉的**线性插值**：起点 + 比例 ×（终点 − 起点）；
- 在姿态空间，"差"要靠矩阵乘法取、"按比例"要靠矩阵幂——落地成的那条轨迹，和四元数 Slerp、轴角插值的结果**一模一样**。

**换句话说：Slerp 那个看起来高深的公式，其实就是姿态空间里的"直线插值"**——只不过这条"直线"是弯曲空间里的直线，即前面说的测地线。

再往后你还会看到：机器人运动学就是把一个个 SE(3) 位姿"叠"在一起；用李代数（旋量）描述关节引起的运动，用伴随映射（Adjoint Map）把它换算到不同参考系；运动规划里的随机采样、优化里的雅可比、动能的度量……原本散落各处、各写各公式的概念，被一套语言**大一统**了。

!!! example "一个开脑洞的小例子：怎么求"平均姿态"？"

    对同一个姿态测了 $n$ 次，得到 $n$ 个旋转，"平均旋转"是什么？直觉的做法——欧拉角直接平均、四元数直接平均——**都是错的**：因为"平均"这个操作隐含了"空间是平的、可以加减"的假设，而姿态空间是弯的（好比求"东经 175° 和西经 175° 的平均"会得到 180° 对面去）。在李群上，连求平均都值得重新思考，需要用优化数值求解。详见作者的知乎回答[《获得多个旋转矩阵，如何获得平均旋转？》](https://www.zhihu.com/question/439497100/answer/1683258444)。

## 四、应用一：让姿态"拐弯"不磕碰——姿态插值与轨迹过渡

进入重头戏：用两个真实问题展示这套语言的威力。它们的共同点：**传统方法要么做不了、要么做得很别扭，而群语言下解法几乎是"显然"的。**

第一个问题来自轨迹规划。假设通过人工示教拿到了机器人要经过的几个路径点，要把它连成连续路径。物理上有个硬约束：**惯性的存在使速度的大小和方向都不能突变**。

![直线插值连接路径点，过渡点速度方向突变](../docs/images/path-blend-velocity-jump.webp)

用最简单的直线插值连接路径点，在过渡点 B 处速度方向会**瞬间跳变**——实际执行时要么轨迹跑偏，要么机器人被迫减速到零再重新出发，牺牲精度和节拍。

教材的答案是：在过渡点用**圆弧或多项式曲线**抹圆角，让速度方向平滑变化。位置空间里这很好办。那问题来了——**姿态空间的"圆弧、多项式曲线"怎么定义？**

有人会说：四元数不是有 Slerp 吗？但上一节刚讲过，**Slerp 只是姿态空间里的"直线"**。让刚体依次经过三个姿态、用 Slerp 两两连接，过渡点处角速度方向照样突变：

![三姿态 Slerp 插值：过渡点角速度方向突变](../docs/images/slerp-three-poses.webp)

群语言下，答案水到渠成。回忆 **Bezier 曲线**是怎么构造的：$n$ 阶 Bezier 就是"$n$ 层线性插值的嵌套"。我们已经有了任意李群空间的"线性插值"（上一节的统一套路），把它嵌套起来，就自动得到了**任意李群空间的 Bezier 曲线**：

![Slerp 与 5 阶 Bezier 过渡对比](../docs/images/slerp-vs-bezier.webp)

如上图：Slerp（左）在过渡点角速度方向跳变；群上的 Bezier 过渡（右）角速度方向连续变化，一路丝滑。学术界近几年还在 ICRA、IROS 上不断发表高阶连续姿态插值的论文——而掌握了群的语言，这套方法你自己就能推出来。

## 五、应用二：端水不洒——在"天生合法"的空间里规划

第二个问题更有意思。机械臂的主要用途之一是搬运，某些搬运任务对**整条轨迹**都有要求：比如端一杯水，全程水面要保持水平；再进一步，想端得**快**，轨迹就要满足动力学约束（加速度大，水会洒）。

作者拿一道他们组的编程笔试题做例子：一个**只能水平移动 + 一个旋转自由度**的机构，把一杯水从左边运到右边，水不能洒。

![一维端水问题](../docs/images/water-cup-1dof.webp)

**第一步：找出约束。** 中学物理就够：水不洒的条件是"水平加速度与重力的合加速度，方向恰好垂直于杯面"。所以水平加速度 $a$ 和杯子倾角 $\theta$ 是**一一对应**的——加速度多大，杯子就该倾斜多少来"抵消"。

**第二步：换个空间建模。** 常规思路是把它当成带约束的优化问题硬解。但这里有个更聪明的观察：这个问题表面上有 2 个自由度（位置 + 角度），**实际自由度只有 1**（加速度定了，角度就定了）。那就干脆定义一个"合成空间"：加速度 $a$ 配上它对应的倾角 $\theta$——在这个空间里**随便选一个点都自动满足约束**。

再考虑"加速度不能突变"，在这个合成空间的切空间（加加速度 jerk 层面）随机采样、沿积分链往下走（jerk → 加速度 → 速度 → 位置；加速度 → 倾角），无论采到什么输入，机构的运动**永远**满足端水约束：

![在合成空间切空间随机采样，任意输入都满足约束](../docs/images/r1so2-sampling.webp)

推广回真实的六轴机械臂高速搬运液体：同样能构造出这样一个"天生合法"的空间。一个原本六自由度、带动力学约束的复杂问题，**坍缩成了三自由度的简单问题**：

![机械臂高速动态搬运液体演示](../docs/images/dynamic-transport.webp)

这个思路和"自主规划"一章的"带约束规划"一脉相承：**与其在偌大的空间里随机采样、再把不合格的样本投影回约束面，不如直接把"始终满足约束的子空间"构造出来，在里面为所欲为。**
